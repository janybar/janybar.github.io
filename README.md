# Цветовой дзен

Главная игра — самостоятельная браузерная реализация основной механики **Color Zen**, геометрической головоломки Cypronia / Large Animal. Это не раскраска по номерам: игрок сталкивает фигуры и меняет цвет всего поля. Уровни, визуальная композиция и синтезированный звук в проекте собственные.

## Правила

- Двигать можно фигуры со светлым ободком. Совпавшие цвета заливают поле и поглощают открытые фигуры этого цвета.
- Вложенные фигуры раскрываются после удаления внешней оболочки; текущая заливка их не поглощает.
- Белая фигура соединяется с любым цветом. Чёрная удаляет пару, не меняя фон.
- Двойное касание пунктирной фигуры переключает защиту от заливки. Защита не блокирует непосредственное столкновение.
- В главе «Отражение» связанные фигуры двигаются зеркально.
- Победа: не осталось фигур, а фон совпал с цветом рамки.

120 собственных уровней, шесть глав, отмена, свободный выбор уровней, сохранение позиции, подсказка по запросу. Нет таймера, очков и ограничений на попытки. Музыка включается кнопкой ♪. Мышь и сенсорный экран поддерживают перетаскивание, клавиатура — выбор через Tab / Enter / Space, переключение защиты S и отмену Ctrl/Cmd+Z.

## Другие игры

- `/coloring/` — «Тихий цвет», раскраска по номерам с 12 иллюстрациями, жестами масштабирования, коллекцией, PNG-экспортом и сохранениями.
- `/water-sort/` — «Тихая вода», Water Sort с проверенными уровнями, задачей дня, рекордами и победными фракталами.

## Запуск и офлайн-работа

Для GitHub Pages выберите корень ветки с этими файлами. Сборка и внешние зависимости для игры не нужны:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://localhost:8765`. После первой загрузки и установки service worker все три игры доступны без сети. Новая версия кешируется целиком; кнопка обновления появляется в настройках. Сохранения принадлежат конкретному браузеру и устройству.

## Проверки

```sh
node tests/zen.test.js
node tests/service-worker.test.js
node tests/coloring.test.js
node tests/game.test.js
node tests/animation.test.js
node tests/solver.test.js
node tests/puzzle.test.js
node tests/victory.test.js
```

`tests/zen.test.js` проверяет правила и решение всех 120 уровней. Браузерные тесты: `tests/zen-browser.cjs`, `tests/coloring-browser.cjs`, `tests/browser.cjs`. Они требуют сервер на 8765, Chrome с `--remote-debugging-port=9226` и модуль `ws` (поддерживается системная установка Debian).

Источники о референсе: [официальная страница Nintendo](https://www.nintendo.com/us/store/products/color-zen-switch/), [Color Zen в Nintendo Wiki](https://nintendo.fandom.com/wiki/Color_Zen).
