# Тихий цвет

Главная страница — оригинальная браузерная раскраска по номерам с механикой в духе Zen Color. Статические HTML, CSS, JavaScript и SVG, без сборки и внешних запросов.

- 12 собственных иллюстраций: природа, цветы, уют и узоры.
- Палитра по номерам, подсветка подходящих областей, автоматический переход к следующему цвету.
- Приближение двумя пальцами, перемещение одним, колесо мыши и кнопки масштаба.
- Подсказка находит и приближает оставшуюся область.
- Библиотека, избранное, начатые и завершённые работы, картина дня.
- Сохранение прогресса и выбранного цвета на устройстве; экспорт PNG 1200×1200.
- Светлая, тёмная и системная темы.

Water Sort «Тихая вода» сохранён по адресу `/water-sort/` вместе с уровнями, рекордами, фракталами и проверкой кратчайшего решения.

## Запуск

Для GitHub Pages выберите корень ветки с этими файлами. Локально:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://localhost:8765`. После первой загрузки и установки service worker обе игры открываются без сети. Новая версия кешируется целиком; кнопка обновления появляется в настройках. Сохранения принадлежат конкретному браузеру и устройству.

## Проверки

```sh
node tests/coloring.test.js
node tests/service-worker.test.js
node tests/game.test.js
node tests/animation.test.js
node tests/solver.test.js
node tests/puzzle.test.js
node tests/victory.test.js
```

`tests/coloring-browser.cjs` проверяет раскраску: доступность всех областей, касания, pinch-to-zoom, сохранение, сброс, завершение, коллекцию, избранное, экспорт PNG, мобильную раскладку и офлайн-открытие. `tests/browser.cjs` проверяет Water Sort по новому адресу. Для браузерных тестов нужны локальный сервер на 8765, Chrome с `--remote-debugging-port=9226` и модуль `ws` (поддерживается системная установка Debian).

`tools/build-levels.cjs` — инструмент разработки для подготовки уровней Water Sort. Поиск решения в самой игре запускается только по кнопке. После изменения набора уровней нужно менять версию идентификаторов в `puzzle.js`, после обновления приложения — версию кеша в `sw.js`.
