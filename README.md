# Тихая вода

Water Sort Puzzle для GitHub Pages. Статические HTML, CSS и JavaScript без сборки и внешних запросов.

- 120 исходных раскладок с проверенными решениями и детерминированными вариациями.
- Путешествие с постепенным ростом сложности, задача дня, личные рекорды и звёзды.
- Касания и перетаскивание, очередь следующего переливания, мгновенная отмена.
- Сохранение текущей воды и истории отмены отдельно для путешествия и задачи дня.
- Восемь тем оформления и девять процедурных победных фракталов.
- Проверка кратчайшего решения через A* в Web Worker **только по кнопке**.

Для публикации выберите в настройках GitHub Pages корень ветки с этими файлами. Локальный запуск:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://localhost:8765`. После первой загрузки и установки service worker игра открывается без сети. Сохранения принадлежат конкретному браузеру и устройству. Новая версия устанавливается целиком; если она уже доступна, в настройках появляется кнопка обновления.

Проверки без установки зависимостей:

```sh
node tests/game.test.js
node tests/animation.test.js
node tests/solver.test.js
node tests/puzzle.test.js
node tests/victory.test.js
```

`tests/browser.cjs` дополнительно проверяет касания, очередь, отмену анимации, перезагрузку, ежедневный режим, награды, раскладку и офлайн-открытие. Ему нужны запущенный сервер на 8765, Chrome с `--remote-debugging-port=9226` и модуль `ws` (поддерживается также системная установка Debian).

`tools/build-levels.cjs` — инструмент разработки для подбора раскладок и расчёта ориентиров. Он не загружается в игру. `levels.js` содержит результаты и проверяемые пути решения с одной свободной пробиркой; в браузере поиск не запускается для создания уровней или подсчёта звёзд. После замены набора уровней нужно изменить версию идентификаторов в `puzzle.js` и кеша в `sw.js`.
